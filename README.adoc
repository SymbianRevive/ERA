= ERA

The **E**POC**R**OOT **A**ssistant

Currently, EPOCstrap can create a mountable filesystem image containing
an EPOCROOT that is fully usable from Linux.

== Requirements

- GCC 13.3 or earlier (must be present in PATH)
- Working Internet connection
- Recent version of the Bash shell
- Linux kernel with support for idmaps (all standard kernels since at least major version 6.x include it)

Any requirements deemed required at runtime will be displayed on the screen

== Installation

----
$ git clone --single-branch https://github.com/SymbianRevive/ERA.git era/
$ cd era/
$ bin/epocstrap -h
$ bin/epocstrap -r ~/epocroot.ext4 modern-gcc
----

Then, follow the instructions display on screen.
