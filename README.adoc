= ERA

The **E**POC**R**OOT **A**ssistant, now containerizable in Podman and Docker!

ERA is the Linux toolchain for Symbian mobile development by **SymbianRevive**.

_At minimum_, all Symbian versions based on EKA2 are expected to be supported, with primary focus on Belle and later.

== Usage

Basic understanding of containerized workflow in software development is assumed.

Please note that all commands require appending of `+--device=/dev/fuse --cap-add=SYS_ADMIN+`,
as the case-folding tool relies on the FUSE kernel driver interface (`+/dev/fuse+`) to operate.
Additionally, `+CAP_SYS_ADMIN+` is required to drive FUSE from within a Podman/Docker container.

If this is not acceptable for your use case, check out the `+image+` branch that runs as a virtualized appliance instead.

=== Examples

==== Simple build and test

Build and tag image using Podman:

----
# cd ERA/
# podman build --device=/dev/fuse --cap-add=SYS_ADMIN -t era:latest .
----

Interactive Z Shell inside a mounted host directory:

----
# podman run --device=/dev/fuse --cap-add=SYS_ADMIN --rm -it -v .:/src -w /src era:latest
----

You will probably want to make sure to extract any binary artifacts from EPOCROOT back into your host machine.

==== Using ERA to build MCPE Symbian Edition

----
# git clone "${MCPE_VITA_GIT_URL:?replace this with git repo url}" -b v1.0.7 minecraftpe-vita
# cd minecraftpe-vita
# podman run --device=/dev/fuse --cap-add SYS_ADMIN --userns=keep-id --rm \
  -v ".:/src:idmap=uids=$(id -u)-1001-1" -w /src \
  era:latest \
  zsh -c 'sbs -j8 -c armv6 -b handheld/project/symbian/group/bld.inf && handheld/project/symbian/group/makesis.sh'
----
